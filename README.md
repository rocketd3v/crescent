# Crescent

you can use arrow keys or TAB to navigate the menu, and return to select an option from the menu

Total time taken: 13h 2m


Game loop:
1) explore the world
- walk around and discover stuff

2) Investigate stuff
 - read letters
 - examine pictures
 - examine records of some sort that proves your friend used to exist

3) slowly feed the player pieces of the mystery

4) progress somehow

# How to run from source
requirements: (check requirements.txt)
python 3
pygame
pytmx
pillow

clone the repo:

git clone https://github.com/rocketd3v/crescent.git
cd crescent

install the required dependencies:
pip3 install -r requirements.txt

to run game:
python3 main.py
